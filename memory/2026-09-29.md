# 2026-09-29 时间甘特可读性与 dev 验收

## 实施

- 按确认方案将阶段进度甘特拆为独立 `TimelineGantt` 展示组件与 `timelineScale` 1.0.0 日期几何算法；不新增依赖，不修改后端、排期、鉴权或附件服务。
- 每条检查项独立一行，完整名称在固定信息列换行；右侧计划条保持真实包含首尾日的宽度。默认 72px/周，支持 56/72/96/128px 缩放、阶段折叠和定位今天，年月/ISO 周分层表头只保留一处今天标识。
- 名称/条形选择继续联动下方原有详情，保留状态保存、负责人、附件与审计入口。停用检查项不进入甘特；模块/负责人筛选排除无匹配检查项的阶段。
- 浏览器定位并修复三处宽度问题：图表外层 grid 子项最小宽度、详情审计 grid、下方状态表格 grid；内部宽表滚动不再撑开整页。窄屏应用标题单独占一行，避免被用户操作区挤成竖排。
- 规则和边界见 [组件参考](../src/components/README.md)。Graphify 支持的 `update li-bs-auto-status` 成功：693 节点、1569 边；生成目录遵循根仓惯例加入本 SPA 忽略规则，不发布索引产物。
