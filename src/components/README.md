## 检查项列表与附件预览（当前阶段）

检查项页采用一套筛选、服务端分页列表和右侧新增/详情抽屉。页面上方“当前项目”只选择业务上下文；常驻新增表单已移入抽屉，不再与列表筛选重复出现。下方阶段一记录保留当时的迁移范围，不表示检查项仍未迁移。

- 列表默认每页 20 条，可选 20/50/100；关键词、阶段、模块、状态及高级筛选交由服务层查询，条件变化回到第一页。详情按 ID 独立读取并校验当前项目归属，列表展示后端附件计数，不用当前页替换甘特的完整检查项数组。
- 复用共享 `SideDrawer`，检查项面板桌面宽 760px、窄屏全宽，底部保存区独立于正文滚动。“基本信息 / 附件 / 操作记录”分区保持挂载，切区不丢正文、说明或待上传文件草稿。检查项图片缩略图只在附件分区可见时读取；切走即取消请求并释放 Blob URL，迟到响应不得保留 URL，再进入时重新加载。
- “保存检查项”一次提交标题、阶段、模块、计划、负责人、状态、启用状态和表单负责的扩展字段；非完成状态保留已有进度。必填及倒序日期在提交前提示，保存和项目加载期间锁定相关操作。
- 负责人只通过带 IDaaS 身份的候选列表维护。明确清空与未提交不是同一操作；服务层不再附带自由文本负责人写入。精确替换和兼容快照规则只维护在[后端 canonical API](../../../li_sicar/api/li-bs-auto-status/v1/README.md)。
- 正文保存、附件上传/删除、附件说明保存是独立操作。新检查项的首附件先保存基本信息取得 ID；已有检查项上传不暗中提交未保存正文。附件已成功保存后，取消正文不会撤销附件。
- 多文件顺序上传，部分失败仅移除成功前缀并回读已生效状态；保留失败和未尝试文件供重试，不宣称整批回滚。回读失败提示先核实，避免重复创建或上传。`RelatedDraftContext` 按编辑会话隔离，附件说明与待上传文件参与关闭、导航和页面离开保护。
- 对象操作记录独立分页；附件访问审计属于附件对象，不等同于检查项对象记录。删除入口以 `canDelete` 为准，受保护的默认检查项提示停用，不改后端硬删除策略。
- 检查项、重点问题和碰撞一页纸复用 `AttachmentList`、`useAttachmentPreview`、`useAttachmentDownload`；受控文件只经 `src/services` 读取，使用 API 基址、凭证和取消信号，不直接绑定受保护 URL，也不信任后端提供的任意预览/下载地址。
- 图片预览仅接受明确类型的安全 raster 格式；PDF 使用精确版本 `pdfjs-dist@6.3.289`，按需加载本地 worker 和 canvas 阅读组件，支持逐页翻阅。Office、CAD、压缩包本阶段仅提供受控原件下载，不接外部转换或预览服务；SVG/HTML 不内联执行。
- 二进制 service 在解析前拒绝 HTML/JSON 成功响应及已知 MIME、后缀、签名冲突，保留 `403` 的权限错误语义。后端允许某类文件下载不等于 SPA 绕过此校验，尤其不承诺 HTML/JSON 原件可由当前 SPA 下载。有界签名检查不是完整文件解析或恶意内容扫描。
- PDF 不初始化脚本/注释交互 UI 或 XFA；加密、损坏和页面渲染失败有明确提示。关闭、切文件和卸载取消加载/渲染并销毁 worker；图片 Blob URL 在失效时释放。预览抽屉的下载可取消，迟到成功、错误和清理不得影响新对象。
- PDF 抽屉使用有界 flex 容器，工具栏不随长 canvas 被居中裁出视口；页面在独立可聚焦区域滚动，支持键盘滚动。嵌套遮罩不继承父容器外边距；窄屏不靠隐藏整页溢出来掩盖布局问题。
- 删除确认取消时不发写请求、不保存正文或附件说明，也不关闭嵌套图片预览。该行为已有隔离组件回归；真实 dev 的附件删除确认/回执异常仍须按验收记录独立处理，不能据此宣称已解决。
- 预览保持已登录只读能力；上传、说明、删除和原件下载继续要求对应管理员权限。前端隐藏/禁用按钮不是后端授权替代，本阶段不放宽 ACL。

## 分页列表与右侧抽屉（阶段一）

重点问题、碰撞一页纸使用服务端分页列表和独立详情抽屉。列表每页 20/50/100 条，筛选后回到第一页；加载中、空结果和失败重试分别显示。取消旧请求并隔离迟到响应，删除末页最后一条后回退有效页。分页和筛选语义只维护在[后端 canonical API](../../../li_sicar/api/li-bs-auto-status/v1/README.md)。CSV 仍导出完整项目范围，不等同于当前页或当前筛选结果。

- 项目上下文容器使用 `grid min-w-0 grid-cols-1`，宽表仅在 `.table-shell` 内滚动，不以隐藏页面溢出的方式掩盖布局问题；真实有数据列表也应在桌面和窄屏复核。
- `usePaginatedList` 管理查询、页码、总数、取消和刷新，不在 hook 中直接请求网络；服务层保留分页元信息。需要完整的项目、模板和层级目录会遍历分页，指定项目 ID 单独读取，不以目录第一页的首项代替。
- `useRecordEditor` 独立保存对象、正文草稿和已保存基线。打开对象按 ID 读取；保存和新建成功后留在返回对象；附件回读只更新对象，不覆盖尚未保存的正文。详情读取失败可重试。
- 关闭、Escape、遮罩及页内导航遇未保存正文或附件说明先确认；浏览器离开提示未保存修改。保存以及切换项目的加载期间禁止关闭、打开其他对象和字段重复写入。
- `useCaptionDrafts` 保留逐附件说明草稿，保存一个说明或刷新附件不会清空其他未保存说明。两业务抽屉通过 `RelatedDraftContext` 将说明纳入离开保护；底栏明确提示在对应附件旁单独保存，正文保存不会代为提交说明。该保护不泛化为其他未迁移表单。
- 附件上传先保存正文；批量部分失败后仍刷新已保存对象、列表和审计，显示已完成数量，不宣称整批回滚或成功。碰撞图片只将未完成项标为失败；详情回读失败会提示先重新打开核实，避免重复上传。标题为空时不上传。
- 抽屉来自版本化共享包 `@li-sicar/side-drawer`，不在 SPA 内复制。图片预览也进入同一抽屉栈，只有最上层处理 Escape 和焦点循环。主抽屉正文内部滚动，底部保存区独立；窄屏占满宽度，主题由 SPA 提供。
- 对象审计历史单独分页。这里不改变旧项目级审计的全量读取策略，也没有取消 Dashboard 聚合的既有数量上限。
- 模块 × 阶段矩阵（项目检查项）逐个显示同单元格的所有清单，包含停用清单；项目模板源数据矩阵自模板库阶段起改为单元格单按钮 → 单元格抽屉 → 清单编辑抽屉，见下节。项目、阶段、检查项表单及审批/权限流程不在阶段一迁移范围。

共享包边界和同步方式见[共享抽屉说明](../../../libs/side-drawer/README.md)。新增回归命令：

```sh
npm run test:pagination
npm run test:template-matrix
npm run test:drawer-interactions
```

分页测试使用真实 React hook/DOM 覆盖分页、请求取消、草稿与保存定位；矩阵测试渲染实际模板视图；抽屉交互测试渲染实际业务视图验证异步保存、项目加载锁和附件草稿/部分失败，并以有界 AST 检查 App 加载态接线及宽表容器。它们不写 dev 数据，也不替代真实后端 CRUD、附件与三态权限验收。阶段验收状态以[当日记录](../../memory/2026-09-29.md)为准。

## 配置中心抽屉（配置阶段）

项目实例、项目阶段、模块 × 阶段矩阵单元格和模块负责人四类配置统一改为共享 `SideDrawer` 右侧抽屉，与检查项/重点问题/碰撞一页纸同一交互风格；矩阵底部不再保留常驻长表单。网络和权限合同以[后端 canonical API](../../../li_sicar/api/li-bs-auto-status/v1/README.md) 为准。

- 四类抽屉复用 `useRecordEditor`：打开按 ID 独立读取已保存值，取消不发送写请求，未保存修改在关闭、Escape、遮罩与嵌套抽屉场景先确认；保存成功后留在返回对象并重置基线，列表/矩阵只展示已保存值。详情读取失败可重试，迟到响应不覆盖新打开对象，已删除项目不会被迟到响应复活。
- 项目实例抽屉的危险操作区承载物理删除：输入与项目编号完全一致的确认编号才能预检；预检只返回任务与计数、不执行删除；执行失败（如存储清理不可达）保留 `failed` 任务与最近错误证据，重试同一入口续跑；仅预检态可取消。删除成功后清空选中项目并刷新工作区。真实 dev 删除只针对本阶段新建且登记的合成项目。
- 模块负责人抽屉保存时只发一次 `apply-owner` 请求，后端单事务同步当前项目该模块全部检查项；显式清空先确认再同步清空；同步范围只限当前项目，模板源编辑不批量覆盖其他项目。
- 项目阶段抽屉支持编辑、按 `canDelete` 门禁的删除，以及把本阶段检查项整体迁移到其他启用阶段；迁移保留各检查项自身计划日期，矩阵摘要与阶段副标题随之更新。
- 矩阵单元格卡片持续显示条数/完成数/启用数摘要；单元格抽屉展示该单元全部检查项（含停用），支持单元内搜索与负责人筛选、新增（草稿继承模块默认负责人与阶段计划日期）、编辑和受删除保护提示；阶段与模块由单元固定，跨阶段迁移只在阶段抽屉操作。
- 抽屉嵌套（矩阵单元格 → 检查项编辑 → 人员搜索）共用同一抽屉栈：只有最上层响应 Escape，正文滚动锁在全部关闭后恢复；窄屏全宽、明暗主题由 SPA 提供。

## 项目模板抽屉与检查项库（模板库阶段）

项目模板源数据、检查模块维护、清单模板编辑与「从检查项库选择」统一改为共享 `SideDrawer` + `useRecordEditor`，与配置中心同一交互风格；模板视图不再保留内联长表单。检查项库为独立侧边栏视图，条目只关联项目阶段（`phase_key`），模块关联在清单模板抽屉中建立。网络、删除门禁与播种语义以[后端 canonical API](../../../li_sicar/api/li-bs-auto-status/v1/README.md)为准。

- 项目模板抽屉承载模板属性与阶段定义表格编辑；复制草稿会克隆模板及全部清单模板，并通过 `set-items` 重建库条目链接；删除模板级联其清单模板，确认文案明示。阶段 key 用于矩阵列、清单模板 `phase_key` 与库条目归属。
- 检查模块抽屉的危险操作区按引用计数门禁删除：仍被项目检查项引用时禁用按钮并显示计数说明；可删除时确认文案包含级联清单模板数量，后端单事务级联删除并审计。被引用删除返回结构化 409，不再是 500。
- 模板矩阵单元格为单一按钮，打开单元格抽屉列出该格全部清单模板（含停用）并进入清单编辑抽屉；「新增单元格清单」从单元格抽屉进入，草稿预填模板/模块/阶段并生成唯一编码，未触碰的预填草稿不可保存。
- 清单模板的检查项只来自检查项库：抽屉维护已选条目的排序与启停、移除；「从检查项库选择」嵌套抽屉按清单阶段过滤启用条目、已链接条目预勾选且禁选。保存先发属性 PATCH，再按需单事务 `set-items` 整体替换链接集；不再读写旧 `item_templates` JSON。库条目已停用时保留链接并提示播种跳过。
- 检查项库视图按项目模板阶段顺序分组展示条目，关键字（标题/说明/优先级）、阶段、启用状态为客户端筛选，不触发新请求；头部计数保持未筛选总量。行或编辑按钮打开抽屉维护阶段 key（datalist 提供已知阶段）、标题、优先级、排序、启用与说明。
- 库条目被清单模板引用时删除按钮禁用并显示引用计数；未引用条目经确认后删除。若引用计数已过期，后端 409 的 `detail` 在抽屉内原样呈现，条目保留。

## 阶段时间甘特

`TimelineGantt.tsx` 是阶段进度页的纯展示组件，接收已筛选的阶段、检查项和选中项回调；状态、负责人、附件和审计仍由 `App.tsx` 原有详情区及 services 管理。不在组件中请求网络，也不修改业务计划日期。

## 日期与布局规则

`timelineScale.ts` 的算法版本为 **1.0.0**，仅计算当前视图几何，不持久化派生结果。

- 输入仅接受可回读为相同值的 `YYYY-MM-DD` 日期，以 UTC 整数日计算，避免夏令时改变日宽。开始、结束均包含当天；同一天的任务宽度恰为一日。
- 时间范围包含项目、可见阶段和其检查项，外扩一天后对齐周一。检查项超出阶段窗口时仍纳入视图，不改变其原始日期。
- ISO 周一至周日为一列，默认 72px/周，可选 56、72、96、128px/周；长项目扩展画布而不压缩周宽。表头按周四所属年月分组，周标签提示完整日期范围；一周宽的年月标题分两行。
- 缺失、非法或逆序日期不绘制计划条，显示“未设置有效计划日期”，不补造排期。空范围以今天生成安全的查看窗口；今天不在窗口内时不绘制标记，并禁用定位按钮。
- 每条检查项独立占一行，名称完整换行；条形只编码时间和状态，不承载截断名称。桌面信息列 360px，767px 及以下为 180px，列与表头在图表自身滚动区域内固定。
- 缩放保持当前可见时间中心；“定位今天”只改变横向滚动位置。阶段可独立或全部展开/收起。名称和条形都可通过按钮键盘交互选择，下方详情保持原有权限边界。
- 外层面板使用 `min-w-0`；详情和状态表格用零最小宽度的单列 grid，避免子表格把窄屏页面撑宽。应用顶部标题在窄屏独占一行，不挤成逐字竖排。
