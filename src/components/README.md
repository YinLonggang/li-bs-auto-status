## 分页列表与右侧抽屉（阶段一）

重点问题、碰撞一页纸使用服务端分页列表和独立详情抽屉。列表每页 20/50/100 条，筛选后回到第一页；加载中、空结果和失败重试分别显示。取消旧请求并隔离迟到响应，删除末页最后一条后回退有效页。分页和筛选语义只维护在[后端 canonical API](../../../li_sicar/api/li-bs-auto-status/v1/README.md)。CSV 仍导出完整项目范围，不等同于当前页或当前筛选结果。

- 项目上下文容器使用 `grid min-w-0 grid-cols-1`，宽表仅在 `.table-shell` 内滚动，不以隐藏页面溢出的方式掩盖布局问题；真实有数据列表也应在桌面和窄屏复核。
- `usePaginatedList` 管理查询、页码、总数、取消和刷新，不在 hook 中直接请求网络；服务层保留分页元信息。需要完整的项目、模板和层级目录会遍历分页，指定项目 ID 单独读取，不以目录第一页的首项代替。
- `useRecordEditor` 独立保存对象、正文草稿和已保存基线。打开对象按 ID 读取；保存和新建成功后留在返回对象；附件回读只更新对象，不覆盖尚未保存的正文。详情读取失败可重试。
- 关闭、Escape、遮罩及页内导航遇未保存正文或附件说明先确认；浏览器离开提示未保存修改。保存以及切换项目的加载期间禁止关闭、打开其他对象和字段重复写入。
- `useCaptionDrafts` 保留逐附件说明草稿，保存一个说明或刷新附件不会清空其他未保存说明。两业务抽屉通过 `RelatedDraftContext` 将说明纳入离开保护；底栏明确提示在对应附件旁单独保存，正文保存不会代为提交说明。该保护不泛化为其他未迁移表单。
- 附件上传先保存正文；批量部分失败后仍刷新已保存对象、列表和审计，显示已完成数量，不宣称整批回滚或成功。碰撞图片只将未完成项标为失败；详情回读失败会提示先重新打开核实，避免重复上传。标题为空时不上传。
- 抽屉来自版本化共享包 `@li-sicar/side-drawer`，不在 SPA 内复制。图片预览也进入同一抽屉栈，只有最上层处理 Escape 和焦点循环。主抽屉正文内部滚动，底部保存区独立；窄屏占满宽度，主题由 SPA 提供。
- 对象审计历史单独分页。这里不改变旧项目级审计的全量读取策略，也没有取消 Dashboard 聚合的既有数量上限。
- 模块 × 阶段矩阵逐个显示同单元格的所有清单，包含停用清单；每个按钮可回选，写权限控制新增入口。项目、阶段、检查项表单及审批/权限流程不在本阶段迁移范围。

共享包边界和同步方式见[共享抽屉说明](../../../libs/side-drawer/README.md)。新增回归命令：

```sh
npm run test:pagination
npm run test:template-matrix
npm run test:drawer-interactions
```

分页测试使用真实 React hook/DOM 覆盖分页、请求取消、草稿与保存定位；矩阵测试渲染实际模板视图；抽屉交互测试渲染实际业务视图验证异步保存、项目加载锁和附件草稿/部分失败，并以有界 AST 检查 App 加载态接线及宽表容器。它们不写 dev 数据，也不替代真实后端 CRUD、附件与三态权限验收。阶段验收状态以[当日记录](../../memory/2026-09-29.md)为准。

## 阶段时间甘特

`TimelineGantt.tsx` 是阶段进度页的纯展示组件，接收已筛选的阶段、检查项和选中项回调；状态、负责人、附件和审计仍由 `App.tsx` 原有详情区及 services 管理。不在组件中请求网络，也不修改业务计划日期。

## 日期与布局规则

`timelineScale.ts` 的算法版本为 **1.0.0**，仅计算当前视图几何，不持久化派生结果。

- 输入仅接受可回读为相同值的 `YYYY-MM-DD` 日期，以 UTC 整数日计算，避免夏令时改变日宽。开始、结束均包含当天；同一天的任务宽度恰为一日。
- 时间范围包含项目、可见阶段和其检查项，外扩一天后对齐周一。检查项超出阶段窗口时仍纳入视图，不改变其原始日期。
- ISO 周一至周日为一列，默认 72px/周，可选 56、72、96、128px/周；长项目扩展画布而不压缩周宽。表头按周四所属年月分组，周标签提示完整日期范围；一周宽的年月标题分两行。
- 缺失、非法或逆序日期不绘制计划条，显示“未设置有效计划日期”，不补造排期。空范围以今天生成安全的查看窗口；今天不在窗口内时不绘制标记，并禁用定位按钮。
- 每条检查项独立占一行，名称完整换行；条形只编码时间和状态，不承载截断名称。桌面信息列 360px，767px 及以下为 180px，列与表头在图表自身滚动区域内固定。
- 缩放保持当前可见时间中心；“定位今天”只改变横向滚动位置。阶段可独立或全部展开/收起。名称和条形都可通过按钮键盘交互选择，下方详情保持原有权限边界。
- 外层面板使用 `min-w-0`；详情和状态表格用零最小宽度的单列 grid，避免子表格把窄屏页面撑宽。应用顶部标题在窄屏独占一行，不挤成逐字竖排。

## 回归检查

在 SPA 根目录执行：

```sh
npm run type-check
npm run test:timeline
npm run test:zeus-contracts
npm run build
```

`test-timeline.mjs` 覆盖日期拒绝、单日/多日真实比例、长排期、跨年 W53/W01、时区/DST、缩放下限、窗口裁剪、超过 12 项的完整名称、唯一今天标记和空阶段。

实际浏览器验收还应覆盖明暗主题、1920/1366/390px、内部横纵滚动与固定列、缩放/定位、收起/展开、筛选、名称/条形到详情联动及原有状态保存。真实开发环境验收记录见 [2026-09-29](../../memory/2026-09-29.md)。网络和权限契约以[后端 canonical API](../../../li_sicar/api/li-bs-auto-status/v1/README.md)为准；几何测试不替代三态权限验收。
